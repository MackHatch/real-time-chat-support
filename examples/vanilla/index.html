Support Widget Demo

Setup Instructions

  1. Ensure backend is running on http://localhost:3000
  2. Ensure frontend is running on http://localhost:5173
  3. Run npm run build:widget in the frontend directory to build widget.js
  4. Get an inbox ID from your database (or use the default inbox)
  5. Update the data-inbox-id attribute in the script tag below

Demo Page

This is a demo page showing the embedded support widget. The widget will appear as a button in the bottom-right corner.

You can interact with the widget using the buttons below, or use the JavaScript API:

JavaScript API

// Initialize with options
window.SupportWidget.init({
  inboxId: 'your-inbox-id',
  baseUrl: 'http://localhost:5173'
});

// Open the widget
window.SupportWidget.open();

// Close the widget
window.SupportWidget.close();

// Toggle the widget
window.SupportWidget.toggle();

// Destroy the widget
window.SupportWidget.destroy();

Script Tag Attributes

  • data-inbox-id: Optional inbox ID (can also be set via init() options)
  • data-base-url: Optional base URL for the widget iframe (defaults to script origin)
