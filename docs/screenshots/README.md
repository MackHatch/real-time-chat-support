## How to re-capture

1. Start the app with seeded demo data (see root README Quickstart).
2. Log in as `agent@local.test` / `Agent123!`.
3. Hide the demo tour if needed: `localStorage.setItem('showDemoTour', 'false')` then refresh.
4. Capture at ~1920×1080 with lists/charts fully loaded.
5. Overwrite the matching PNG in this directory.
